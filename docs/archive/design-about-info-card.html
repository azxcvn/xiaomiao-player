三项需求的数据从哪来（已核实）
  • 版本号：现成 —— 关于页已用 PackageInfo.fromPlatform() 取 info.version（当前 v1.3.6）。构建号 info.buildNumber（=4）也能顺带拿到。
  • release / debug：现成 —— kReleaseMode / kDebugMode（package:flutter/foundation.dart），零成本、零配置。
  • 构建哈希：Flutter 侧没有现成来源（不像 Android 原生有 BuildConfig），必须二选一：
    • B1 构建脚本注入（推荐）：在 tools/build_*.ps1 里加 --dart-define=GIT_HASH=$(git rev-parse --short HEAD)，Dart 侧用 String.fromEnvironment('GIT_HASH', defaultValue:'unknown') 读。改动小、结论准；代价是必须走脚本构建，用 Android Studio 直接跑时显示 unknown。
    • B2 Gradle 注入 + 原生通道：Gradle 里加一个生成 buildInfo 资源/字段的任务，经现有 moumou/video_info 通道多暴露一个 getBuildInfo 方法（和 getSdkInt 同款写法）。任何构建方式都准，但要多动 android/app/build.gradle.kts 与 MainActivity.kt。
