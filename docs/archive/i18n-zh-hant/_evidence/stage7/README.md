## 走查前提

1. 设备语言设为**繁体**（`zh-Hant` / `zh-TW` / `zh-HK`），否则 H-AND-* 三条验不出来；
2. 用**用户自己出的包**安装（AI 不编译、不装包）；
3. 素材：一份繁体字幕视频、一份简体字幕视频、一个深层 `中文目录`、一个网络源（FTP/WebDAV 任一）。
